# Рефакторинг після перевірки викладача

## Зміни

Сервер розділено на `domain`, `application`, `infrastructure`, `presentation/http` і `composition`. Головний файл `index.ts` залишився точкою запуску. Опис відповідальностей: [організація коду](CLEAN_ARCHITECTURE_UA.md).

Авторизація має окремі схеми Zod, ліміт запитів, сервіси парольного й Google-входу, адаптери bcrypt/JWT/Google OAuth, middleware та cookie. Дубльовану перевірку типу й довжини пароля після Zod прибрано. Сховище отримує `passwordHash`, а не пароль. Тип відсутнього локального пароля явний: `null` для Google-акаунта. Об’єкти користувачів кешуються типізовано.

ШІ-думка виконується через `AiAssessmentService` та `ProviderRegistry`; адаптери провайдерів зареєстровано за пріоритетом. Сценарій перевірки документа винесено в `ScanService`. Чисті алгоритми залишено функціями. Інтерфейси й типи винесено у `types` та `ports`, CSS — у `client/styles`, тести — у `tests/unit` і `tests/e2e`.

Старі згенеровані `.vercel-server/*.js` вилучено з індексу Git; каталог генерується командою збірки й ігнорується. Vercel-адаптер посилається на нове розташування HTTP-модуля.

Недійсний переданий JWT тепер повертає `401 SESSION_INVALID`; очищення клієнтського стану та навігація на `/login` виконуються окремо. Відсутність токена залишає доступними гостьові сценарії.

Діаграми замінено невеликими Mermaid-схемами архітектури, об’єктів і послідовностей. Старі детальні draw.io-артефакти поточного перегляду замінено Markdown-файлами.

## Перевірено

- Повний Vitest: **45 файлів, 217 тестів**, усі успішні.
- ESLint для вихідного коду та модульних тестів: без помилок і попереджень.
- `npm run build`: серверна компіляція, перевірка TypeScript та Vite/PWA-збірка успішні.
- Зібраний Vercel-адаптер: `/api/health` повертає 200, недійсна сесія на `/api/auth/me` — 401.
- Нові регресії: сховище отримує лише хеш; одноразова перевірка пароля; Google-only акаунт; збереження пароля під час прив’язування Google; порядок/унікальність провайдерів; межі шарів; розташування CSS і тестів; клієнтська подія 401 та перехід на логін.

## Межі перевірки

Реальний Google OAuth, платні API, сесія після закриття браузера та візуальна перевірка в браузері в цей прогін не входили. Автоматичні перевірки не доводять їх працездатність у production. Очищення старого локального каталогу збірки було відхилене політикою виконання; файли на диску залишено, їх вилучено лише з версійного обліку. Перевірено нову скомпільовану точку входу.

Незалежні зміни дипломних документів, Python-скриптів та правило `.idea/` у `.gitignore` збережено поза комітами рефакторингу.
