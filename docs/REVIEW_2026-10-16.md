# Перегляд застосунку — 16 жовтня 2026 року

## Обсяг

Перевірено підготовку тексту, зіставлення джерел, локальну ШІ-евристику, інструкції LLM, діагностику провайдерів, сторінку результатів, експорт і документацію. Це перегляд реалізації з регресіями; не незалежна наукова валідація та не повний аудит безпеки всієї інфраструктури.

## Знайдені проблеми та зміни

| Проблема | Зміна |
| --- | --- |
| Кілька джерел/URL могли штучно знизити ШІ-бал | Прибрано бібліографічне обнулення звичайної прози; цитування нейтралізується |
| «Я не можу» сприймалося як відмова ШІ | Звичайні відмови виключені, спеціальний floor стосується самовизначення моделі |
| «Як» рахувалося як обережне формулювання | Виправлено словник |
| Пунктуація, безособовий стиль, стандартна мета роботи впливали на авторство | Це контекст, виключений із каналів і бонусів оцінювання |
| Абзаци втрачалися під час очищення | Збережено структуру рядків; рівномірність абзаців залишається нейтральною до авторства |
| Згадка references/списку джерел могла відрізати корисний текст | Перевіряється заголовок або структура бібліографії; додатки не виключаються автоматично |
| Сильний snippet міг витіснити слабше прочитане джерело | Прочитане джерело має пріоритет; snippet не підміняє результат перевірки |
| Повне покриття й обрізаний список доказів не пояснювалися | Додано загальну кількість збігів/унікальних URL і повідомлення про обмежений список |
| Помилки публічних API виглядали як успішний порожній пошук | HTTP/network-збої збережені в діагностиці |
| «Квота Google» була універсальним написом для всіх збоїв | Квота, доступ, timeout і недоступність розрізняються |
| Довгі списки джерел і вузькі картки ускладнювали читання | Джерела після підсумку, перші 6 записів із розгортанням; ознаки моделі на повну ширину; переходи до розділів |
| PNG-експорт завершував індикацію до готовності зображення | Promise завершується після створення PNG; помилки відображаються |
| Сила джерела в експорті виглядала як % плагіату | Для джерела використовується бал /100 |
| Drive access token зберігався у localStorage | Перенесено в пам'ять сторінки, старі копії видаляються; вихід очищає токен |
| Документація містила старі формули, провайдери та обіцянки | README, архітектура, інструкція звіту та Vercel переписані за кодом |

## Перевірка малого корпусу

`npm run calibrate` на поточних синтетичних прикладах: 8 human, 8 ai, 7 mixed, 7 paraphrased. При порозі 45: TP=4, FP=0, TN=8, FN=4 для чистих human/ai-груп. При порозі 70: TP=1, FP=0, TN=8, FN=7. При порозі 45 перевищення було у 2/7 mixed і 5/7 paraphrased.

Висновок: навіть на цьому малому наборі поріг не знаходить усі генерації; низький бал не доводить людське авторство. ROC-AUC цього набору не переноситься на реальний світ. Не підбирали ваги для досягнення красивих чисел цього корпусу.

## Верифікація

Додані регресії для згадок бібліографії, збереження абзаців, пріоритету прочитаної сторінки, чесної діагностики HTTP-помилок, розгортання джерел та асинхронного експорту. Підсумкова перевірка: 197 тестів у 39 файлах пройшли; production-збірка, TypeScript і ESLint завершилися успішно.

Браузерний перегляд локальної адреси заблокований збереженою політикою браузерного інструмента. Інший браузер, CDP чи screenshot-обхід не використовувалися. Реальні desktop/mobile екрани, живий Google OAuth/Drive, платні провайдери та production Redis у цьому перегляді не перевірялися. DOM-тести й перевірка CSS не є візуальним прийманням.

## Залишкові обмеження

- Стилометрія залежить від жанру й мови; ритмічні та лексичні ознаки частково корелюють.
- Невелика кількість перекривних вікон не дає незалежних свідчень авторства.
- ШІ-думка може не виконати інструкцію або впевнено помилитися.
- Вебпошук не гарантує повного охоплення, дослівне покриття не вимірює всі перефразування.
- Автоматичне вилучення коду, цитат і службових частин — евристичне; користувачу варто перевіряти обсяг.
- PDF/PNG є стислими експортами; довгі матеріали слід переглядати у звіті/JSON.
- Для великих upload на Vercel потрібен окремий потік через сховище; серверний ліміт 50 MiB не скасовує нижчий ліміт платформи.
- Google Drive використовує окремий OAuth-дозвіл; після перезавантаження сторінки може знадобитися повторне отримання доступу. Живий потік Drive не перевірявся.
- Нові правила застосовуються до нових перевірок, старі звіти автоматично не перераховуються.
