# Як читати звіт «Незбіг»

## З чого почати

1. Перевірте назву документа й кількість проаналізованих слів.
2. Перегляньте відсоток знайдених збігів і попередження про пошук.
3. Відкрийте підтверджені джерела. Порівняйте уривки, контекст, лапки та посилання.
4. Прочитайте локальний ШІ-індикатор разом із надійністю та поясненнями. ШІ-думка — окрема додаткова оцінка.

Швидкі переходи ведуть до джерел і розширеного ШІ-аналізу. Список починається з шести найсильніших записів; решту показує кнопка. Приховування решти списку не змінює відсотки.

## Чотири різні показники

| Показник | Що означає | Чого не означає |
| --- | --- | --- |
| Плагіат · знайдені збіги | Частку слів у підтверджених точних послідовностях | Остаточне встановлення плагіату |
| Сила збігу, наприклад 85/100 | Схожість фрагмента з конкретним джерелом | 85% плагіату в усьому документі |
| ШІ-аналіз | Некалібрований локальний індикатор стилю | Імовірність того, що автор — ШІ |
| ШІ-думка | Відповідь окремої мовної моделі за обмеженою вибіркою | Незалежний доказ або заміну основного аналізу |

Наприклад, 2,8% дослівного покриття й 85/100 сили найкращого збігу не суперечать одне одному: невеликий фрагмент може дуже точно збігатися з джерелом. Цитований фрагмент також може входити в покриття. Перефразування чи невідоме джерело можуть залишитися непоміченими.

## Джерела й підказки

«Сторінку підтверджено» означає, що для порівняння доступний текст джерела; для академічних API це може бути анотація. Це не підтвердження порушення доброчесності.

«Лише пошукова підказка» означає, що пошуковий сервіс показав можливий результат, але достатнього тексту джерела немає. Підказка не збільшує підтверджений відсоток збігів.

Одна сторінка може мати збіги з кількома фрагментами документа. Тому кількість записів не завжди дорівнює кількості унікальних джерел. Сервер зберігає до 24 найсильніших записів. Якщо прийнятних збігів більше, повідомлення пояснює, що загальний відсоток охоплює також записи поза цим списком.

## ШІ-аналіз і надійність

Наявність джерел не доводить людського авторства, відсутність джерел не доводить генерації. Те саме стосується оформлення, безособового наукового стилю, простих розділових знаків, займенника «я», помилок і таблиць.

Пояснення показують повтори, ритм та словник. Схожі показники можуть описувати одну й ту саму особливість, тому кілька ознак не дорівнюють кільком незалежним доказам. Інструкції, технічні описи та стандартні форми часто повторюються незалежно від автора.

Короткий текст дає «недостатньо даних», обмежена мовна підтримка — невизначений результат. Низький індикатор не засвідчує людського авторства. Високий не є підставою для автоматичного звинувачення.

## Помилки й обмеження пошуку

- «Вичерпано квоту» — провайдер повідомив про ліміт; це не універсальна назва всіх помилок.
- «Перевірте доступ API та налаштування ключа» — власнику розгортання слід перевірити доступ і конфігурацію сервісу.
- Timeout або недоступність — запит не завершився. Спробуйте пізніше.
- Частковий збій — знайдені докази залишаються корисними, але пошук обмежений.
- Якщо жоден пошуковий запит не завершився успішно, відсоток показано як «—». Це не 0% і не підтвердження унікальності.

## Виключений текст та експорт

Титульна частина, розпізнана бібліографія й код можуть бути виключені з вебперевірки. Для локального ШІ додатково вилучаються довгі цитати й маркери цитування. Перевіряйте кількість виключених слів у технічних відомостях і розширеному аналізі.

PDF і PNG містять стислий звіт із першими п'ятьма джерелами. JSON містить структуровані дані доступного звіту. Експорт може включати фрагменти початкового документа — врахуйте це перед передаванням іншим людям. Приватне посилання історії відкривається лише в обліковому записі власника.

Оновлення алгоритму не переписує старі збережені звіти. Для нової оцінки перевірте документ повторно.
